# 硬體

狀態：尚未建立設計。

本目錄未來存放原理圖、PCB、必要零件庫與硬體驗證說明。確定板子種類後再建立子目錄；目前不預設板數或元件。

第一份實際專案加入時請填寫：
- 現行專案檔入口與板版號。
- KiCad 或其他 EDA 工具版本。
- 共用 Symbol／Footprint／模型來源與授權。
- 開啟步驟與相對路徑設定。
- 負責人、編輯安排、ERC／DRC 與驗證狀態。

同一張 PCB 同時間指定一位編輯者。自動備份不作為正式設計來源。

## 放置位置

- [boards/](boards/README.md)：每張板的來源專案。
- [libraries/](libraries/README.md)：共用 Symbol、Footprint 與模型。
- [datasheets/](datasheets/README.md)：必要規格書與硬體參考。
