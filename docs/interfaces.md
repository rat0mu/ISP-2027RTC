# 介面規格草案

狀態：草案／尚未定案。

目前只有規格格式，沒有已生效的硬體或軟體介面。每項確認後透過 PR 更新，並由受影響模組的負責人確認。

| 介面 ID | 提供方 → 使用方 | 定義／單位／時序／無效值 | 版本與狀態 | 負責人 |
| --- | --- | --- | --- | --- |
| 待建立 | 待確認 | 待確認 | 草案 | 待指定 |

建立介面時按用途選填：

- 電氣：供電、電平、接頭、腳位與限制。
- 通訊：傳輸方式、欄位、位元組順序、版本、校驗與逾時。
- 資料：單位、座標軸、時間基準、更新率與無效值。
- 機構：尺寸、孔位、接頭空間、裝配與維修空間。
- 驗證：如何確認雙方實作符合介面。

介面變更時列出受影響模組、相容性、遷移方式與驗證需求。
