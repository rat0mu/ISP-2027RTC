# 元件選型總表

狀態：草案。最後更新：2026-11-14。

本表列出主系統與備援系統目前的元件選擇，方便隨時查看與修改。選擇的理由與代價寫在 [設計決策](decisions.md)；本表只放結論。

## 如何修改

1. 直接修改下表對應的格子，並更新上方的「最後更新」日期。
2. 狀態欄只用以下四種：
   - 候選：還在比較，尚未寫成決策。
   - 提案中：已寫入 decisions.md，待團隊確認。
   - 採用：團隊已確認。
   - 已取代：保留原列，並在備註寫出換成什麼與原因。
3. 換掉提案中或採用的元件時，同步修改 decisions.md 對應的決策；影響架構或介面時，一併更新 [系統架構](architecture.md) 與 [介面規格](interfaces.md)。
4. 在下方「修改紀錄」加一行。
