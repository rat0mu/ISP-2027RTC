# 測試與版本

本文件提供操作與說明；協作要求以 [CONTRIBUTING.md](../CONTRIBUTING.md) 為準。

## 測試與版本紀錄

### 回報驗證程度

| 說法 | 能支持的結論 |
| --- | --- |
| 文件已審查 | 文件經閱讀或連結檢查，依實際方法描述 |
| 建置成功 | 在指定環境與組態下產生建置產物 |
| Host 測試通過 | 指定邏輯在電腦端案例中符合預期 |
| 板級驗證通過 | 指定硬體、韌體與條件下的板級結果 |
| 整機驗證通過 | 整合後在指定條件下符合驗收 |
| 待驗證 | 尚未完成需要的檢查，需列後續事項 |

每次結果至少記錄來源版本、環境與組態、方法、預期、實際結果及未完成事項。有自動測試時，失敗應回傳可辨識的非零退出碼，避免只列印 FAIL 卻被當成成功。

### 里程碑與發布

main 是團隊已接受的整合基準。製造、整機測試與飛行使用的里程碑，另外固定版本與證據。

目前尚無正式 tag 或 release。未來發布時記錄：

| 資訊 | 內容 |
| --- | --- |
| 硬體 | 板版號、來源與製造輸出 |
| 韌體 | 各角色 commit、產物與建置環境 |
| 地面站 | 使用版本與協定相容性 |
| 組態 | 角色、profile 與必要參數 |
| 驗證 | 方法、結果與原始證據位置 |
| 限制 | 已知問題與未完成事項 |
